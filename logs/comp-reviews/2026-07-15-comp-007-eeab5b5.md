## Implementation and constraint closure
I traced the scoring path in `analyze.py` from `candidates.json` and `bioactivity_data.json` into `outputs/ranking.json` and `outputs/summary.md`.

Implementation closure findings:

- **Potency axis:** implemented as `1 / mean_class_i_ic50_nM`, max-normalized across scoreable candidates. Direct HDAC1/2/3 values are geomeaned; otherwise `effective_HDAC_class_I_IC50_estimate_nM` is used.
- **Selectivity axis:** implemented as `ratio / (ratio + 10)`, where `ratio = HDAC6_IC50 / mean_class_i_ic50`. This is equivalent to `HDAC6_IC50 / (HDAC6_IC50 + 10 × mean_class_i_ic50)`.
- **Gut-selectivity axis:** implemented only as `1 - oral_bioavailability_fraction`.
- **Composite:** `potency_norm × selectivity_score × gut_score`, with `DATA_UNAVAILABLE` forced to zero.

Load-bearing implementation gaps:

1. **Formula documentation mismatch.** README and generated summary describe selectivity as `HDAC6_IC50 / (HDAC6_IC50 + mean_class_I_IC50), midpoint ratio=10`. That omits the implemented `10 × mean_class_I_IC50` denominator term. The archive’s scoring table is clearer, but the generated summary and README remain misleading.

2. **Stored gut concentration is not used.** `typical_gut_concentration_uM` is stored and emitted, but not scored or compared to class-I IC50. This is a dominant physiological constraint for the stated question. Examples:
   - Butyrate: ~1000 µM gut concentration vs ~12 µM class-I geomean — comfortably above biochemical IC50.
   - Sulforaphane: ~10 µM gut estimate vs ~5 µM estimated effective IC50 — barely above estimate and mechanism is indirect.
   - PEITC: ~5 µM gut estimate vs ~10 µM estimated effective IC50 — likely below the artifact’s own estimate.
   - DADS: ~200 µM gut estimate vs ~1000 µM estimated IC50 — likely sub-IC50.
   
   The current model treats gut exposure only via oral bioavailability, not via actual concentration relative to potency. This means the “gut-enriched exposure profile” question is only partially implemented.

3. **Cellular/nuclear access is not modeled.** HDAC1/2/3 are nuclear targets. The computation does not model enterocyte uptake, intracellular metabolite formation, nuclear exposure, time above IC50, or HDAC residence time. This is especially important for sulforaphane and PEITC, where the artifact itself says the mechanism is indirect protein-level downregulation rather than direct biochemical zinc chelation.

4. **Safety selectivity is under-closed.** HDAC6 selectivity is used as the sole off-target safety axis. The artifact repeatedly frames HDAC6 avoidance as the chronic-safety determinant, but it does not source or model broader class-I HDAC inhibition risks, systemic exposure, epigenetic off-targets, or cardiotoxicity mechanisms outside HDAC6. The “HDAC6 is the primary driver of pan-HDAC cardiotoxicity” framing is not directly verified in the artifact.

5. **Censored HDAC6 value is numerically handled as a point value.** The revised text now correctly calls butyrate HDAC6 IC50 `>2 mM` and the 167× ratio a lower bound. The code still stores `2000000` as a numeric point and computes 166.7× / 0.9434. This is acceptable only if the output consistently labels the result as a lower bound. Most prose now does; some table cells still display `2,000,000` and `167×` without `>`/`≥`.

6. **`hdac_targets.json` is loaded but not used for scoring or output beyond hard-coded target IDs.** Its localization, role, and cardiotoxicity fields are documentation-only despite being mechanistically important.

7. **`used_estimate` is misleading for DATA_UNAVAILABLE compounds.** For caffeic and ferulic acid, all direct IC50s are null and the estimate is also null, but the code sets `used_estimate = True`. The summary hides this because the mean IC50 is `N/A`, but `ranking.json` is misleading.

Constraint closure:

- **Reaction/target closure:** The computation ranks inhibitors of HDAC1/2/3 with HDAC6 as off-target. It does not model the HDAC deacetylation substrate, histone acetylation state, HSF1/Hsp90 induction, ABCG2 trafficking, or urate flux.
- **Operating concentration closure:** Incomplete. Oral BA is used as a proxy, but gut concentration relative to IC50 is not part of the score.
- **Mass balance / exposure time:** Not modeled. No residence-time or time-above-IC50 calculation.
- **Localization / transport / diffusion:** Not modeled. This is material for enterocyte uptake and nuclear HDAC access.
- **Coproducts / redox / safety:** No coproduct burden is relevant for HDAC inhibition per se, but systemic HDAC effects and HDAC6/class-I safety are not closed.
- **Sensitivity range:** No sensitivity analysis is implemented for the arbitrary 0.30 unknown-HDAC6 penalty, selectivity midpoint 10, oral BA estimates, or effective IC50 estimates. Those are dominant uncertainties.

## New connections or implications
The main lost implication is that **butyrate’s apparent advantage is not just potency/selectivity but operating-regime margin**: its expected colonic concentration is tens to >100× its class-I IC50, whereas SFN/PEITC are near or below their estimated effective class-I values and have indirect mechanisms. If the model adds a concentration/IC50 exposure factor, butyrate likely remains rank 1 more strongly, while PEITC and DADS may fall as actionable Stage 2 priorities.

A second implication is that **Stage 2 should be designed as a mechanism-resolving assay, not merely a ranking confirmation**: paired Caco-2/HepG2 HDAC activity should include intracellular/nuclear exposure, HDAC1/2/3 activity, HDAC6/tubulin readout, and ABCG2-Q141K surface trafficking/urate flux, because the current computation cannot distinguish direct zinc-chelation HDAC inhibition from transcriptional downregulation of HDAC proteins.
