## Implementation and constraint closure
The executable path is straightforward and deterministic:

- `analyze.py` loads `inputs/model_parameters.json`.
- It iterates `3^8 = 6,561` full-factorial grid cells over the eight entries in `full_factorial_levels`.
- `dietary_ledger()` uses:
  - `dietary_purine_units`
  - `gr5_nucleoside_intercept_fraction`
  - `whole_cell_microbial_salvage_fraction`
  - `nucleoside_absorption_fraction`
  - `free_base_absorption_relative_to_nucleoside`
- That dietary ledger is genuinely conserved; every grid cell asserts sum equals 100.
- `architecture_capture()` uses:
  - `uox_capture_fraction`
  - `pdb_capture_fraction`
  - `well_mixed_shared_pool_overlap`
  - `staged_residual_transfer_efficiency`
- It returns capture fractions only. It does **not** multiply by or conserve `endogenous_luminal_urate_units`.

Stored-but-unused / documentation-only findings:

- `endogenous_luminal_urate_units` is stored in JSON but unused by code. The new output limitation acknowledges this, but README/provenance/top-level pages have not all caught up.
- `architecture_equations` is stored in JSON but the equations are hard-coded in Python. This is not wrong, but the JSON is documentation rather than an executable source of truth.
- `purpose`, `interpretation_policy`, `query-strategy.json`, and query framings are non-executable documentation.
- Sensitivity lists include parameters irrelevant to each submodel, producing near-zero correlations. This is acceptable but should be understood as full-grid bookkeeping rather than a causal sensitivity model.

Constraint closure:

- **Reaction closure:** The model correctly avoids treating GR-5 DeoD cleavage as purine destruction. It models nucleoside interception followed by either microbial salvage/retention or free-base absorption/unabsorption. It does not model phosphate cosubstrate, exact nucleoside/base species, or host/microbial downstream purine chemistry.
- **UOX/PDB chemistry:** UOX and PDB are abstract capture fractions. Oxygen, H₂O₂, allantoin/oxidative products, yanthine/UMH/albizziin/pyruvate, cofactors, selenium/molybdenum, and anaerobic viability are not mechanistically simulated.
- **Physiological concentration / Km / transport:** No Km, Kd, IC50, measured luminal concentration, transporter capacity, or residence-time calculation is implemented. That is acceptable only because the artifact frames the result as a design-space boundary and pushes physiology to validation §1.34.
- **Mass balance:** Dietary precursor mass balance is closed. Endogenous urate mass balance is **not** closed despite some remaining “ledger” wording.
- **Localization/transport:** Represented only by `well_mixed_shared_pool_overlap` and `staged_residual_transfer_efficiency`. These are scenario parameters, not measured physical transport or diffusion.
- **Safety/off-targets:** Redox burden, coproduct peaks, microbial turnover/re-release, colonization, inflammation, renal compensation, and serum urate dynamics are omitted and acknowledged in limitations.
- **Sensitivity coverage:** The grid covers the named algebraic uncertainties but not dominant physiological uncertainties such as kinetic constants, residence time, oxygen gradients, biomass density, product toxicity, PDB viability, and host absorption rates. The summary largely states this limitation.
