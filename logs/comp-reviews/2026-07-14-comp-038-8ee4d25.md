# Independent comp review — comp-038

## Bottom-line verdict

**Action required.** The scientific first-pass verdict is directionally reasonable as a **triage** result: no ready home/colorimetric/breath butyrate assay is established; HPLC-UV for culture supernatants is the best near-term lab-tier candidate; stool/home remains unresolved. However, the artifact has a **broken reproducibility/implementation contract** and the corpus has **post-artifact propagation drift**: later wiki pages report a full-text verification pass and validation §1.31, but those data/provenance are not present in the comp-038 artifact, while `computational-experiments.md` still describes the earlier abstract-level first pass and still treats electrochemical fecal SCFA profiling as promising.

## Implementation and constraint closure

What I traced:

- `analyze.py` loads `inputs/query-strategy.json` and `inputs/model-config.json`, fetches PubMed metadata through the shared `agentic_lit_synthesis` helper, and can:
  - dry-run check output files exist;
  - prepare a Codex packet;
  - optionally call OpenRouter for query critique / N trajectories / judge.
- The committed run in `outputs/results.json` is **not reproducibly generated by the current default command**:
  - `python3 analyze.py` only checks that outputs exist.
  - `python3 analyze.py --prepare-codex` would write a packet and a “pending Codex synthesis” summary, not the committed ranked verdict.
  - The committed `results.json` has `mode: codex_synthesis_from_packet`, top-level `ranked_candidates`, and qualitative trajectory records; this shape is not what `write_summary()` emits from the current code path.
  - The actual “N=5 Codex in-session synthesis” raw transcript / model output is not committed as a machine-verifiable source artifact. The results appear manually curated from the packet.
- The configured `consensus_threshold` is 3, but all ranked “consensus” winners in `results.json` have `consensus_count: 2`. The artifact labels this (“below formal 3/5 threshold”) but still ranks them. That is a defensible human judgment only if explicitly documented as an override; it is not an implementation of the configured threshold.
- Several inputs are stored as protocol/documentation rather than executable constraints:
  - `target_concentration_ranges` is present in JSON and packet, but the code does not independently enforce range/matrix fit. The OpenRouter `judge_prompt()` hardcodes ranges rather than reading them from the JSON.
  - `output_format_expected` is not enforced; output omits several requested fields such as cost/sample, published GC-MS correlation coefficient, dynamic range per candidate, and commercial availability.
  - `final_green_requires_full_text_or_protocol_evidence` is a prompt instruction / parameter, not a programmatic gate.
  - `verifier` role is configured but never called in `analyze.py`.
  - `budget_usd` and `max_candidates_for_full_pairwise` are stored but not enforced.
  - Translation configuration is present but unused in the artifact run; later wiki text claims multilingual full-text verification, but that pass is not present in the comp folder.
- The PubMed snapshot is title/abstract/citation metadata only. It supports candidate surfacing and rejection of obvious false positives, but not primary-source verification of vendor protocols or method performance.

Constraint closure by assay class:

- **HPLC-UV culture-supernatant candidate (PMID 23542733):**
  - Artifact-level evidence: PubMed abstract reports bacterial culture supernatant method, acidification to pH <2, liquid-liquid back extraction with diethyl ether, UV at 210 nm, matrix-matched calibration 0.5–50 mM, LOD/LOQ ~0.13–0.33 / 0.5–1.0 mM, and use for butyric-acid-producing bacteria.
  - Constraint fit: plausible for mM culture supernatants, but not for serum (~1–10 µM), low-lumenal edge (~10 µM), or unvalidated stool matrices. UV 210 nm is non-selective; medium blanks, co-elution checks, recovery, and GC-MS comparison are mandatory. Diethyl ether / pH<2 sample prep creates safety and handling constraints inconsistent with home Tier 2.
- **Electrochemical fecal SCFA profiling:**
  - Artifact-level evidence: PubMed abstract/snapshot and LLM synthesis only. Full-text performance, hardware availability, training/reference method, butyrate-specific external validation were not artifact-verified.
  - Later wiki text says full-text verification failed this as a Tier 2 option because of vendor-locked hardware, dual derivatization, unreleased ANN, and GC-MS retraining requirement. That later conclusion is not present in the comp-038 artifact.
- **Breath H₂/CH₄ proxy:**
  - The artifact’s RED conclusion is physically/biologically sound at first pass: breath gases are broad fermentation/transit/methanogen signals, not butyrate-specific concentration readouts. Breath SCFA/EBC papers do not establish gut/systemic butyrate quantification.
- **Generic FFA colorimetric/fluorometric kits:**
  - The artifact’s rejection is plausible, but the load-bearing Abcam ab65341 protocol is only cited, not committed or quoted as a directly verified protocol artifact. Treat as unverified-by-artifact until the vendor PDF/protocol is captured.
- **SCFA/butyric-acid ELISA kits:**
  - Artifact-level conclusion is appropriately RED-provisional: vendor claims exist, no GC-MS validation surfaced, and specificity for an 88-Da analyte against acetate/propionate/isobutyrate is a major concern. Later wiki adds dynamic-range failure, but that is not in the comp artifact.
- **Mass balance / exposure / localization:**
  - This comp is an assay audit, not a biological-effect model. It does not measure butyrate production, tissue exposure, enterocyte nuclear concentration, ABCG2 rescue, or clinical effect. It should not be read as evidence that butyrate interventions work—only as evidence about measurement options.
- **Sensitivity coverage:**
  - The artifact covers convenient assay classes and matrices but does not perform formal sensitivity analysis over the dominant uncertainties: matrix interference, extraction recovery, co-elution, stool heterogeneity, instrument availability, and vendor-protocol validity.

## New connections or implications

- The comp’s strongest practical implication is **matrix-splitting**: “butyrate assay” is not one problem. Culture-supernatant butyrate can plausibly be handled by community-biolab HPLC-UV after validation; stool/serum/home butyrate remains unsolved.
- The artifact exposes a broader methodology issue for agentic literature-synthesis comps: when the decisive synthesis is performed “in-session,” the repo needs either raw model outputs or a manually authored synthesis log. Otherwise the comp is auditable as a memo, not reproducible as an experiment.
- The later full-text outcome strengthens validation §1.31 and weakens any remaining corpus language that treats electrochemical+ANN as a near-term Tier 2 solution. Its role should become “interesting paper/citation, not an adoption candidate.”
- For PDB / engineered-strain work, HPLC-UV validation is directly useful for **carbon-fate measurement** in culture supernatants, but it does not close the patient-facing Q141K workflow gap because stool/serum/home matrices remain unvalidated.
