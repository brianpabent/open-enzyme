# Independent comp review — comp-032

## Bottom-line verdict

**Quantitative verdict invalid; action required.** The artifact is reproducible as a deterministic descriptor-ranking exercise, but it does **not** establish that any molecule binds ABCG2 Q141K, rescues trafficking, avoids ABCG2 inhibition, reaches the relevant cytosolic NBD compartment at sufficient concentration, or is a wet-lab/compounding priority. The “positive-control pass” and decoy separation are largely built into the class-prior score, not independently learned from pocket fit.

The cleanest defensible conclusion is: **a hand-curated, prior-weighted library contains several repurposing hypotheses worth real docking and cell assays.** The current GREEN / “repurposing thesis empirically supported” / “do not pivot” language is stronger than the implementation supports.

## Implementation and constraint closure

What I traced:

- `analyze.py` parses the AlphaFold PDB CA atoms, builds a 10 Å CA-centered Q141 pocket descriptor, scores each molecule from `fda_approved_drug_library.json`, applies a composite ≥0.75 gate, then applies a class-diversity filter and writes committed outputs.
- The committed `outputs/screening_results.json`, `outputs/pocket_descriptor.json`, and `outputs/summary.md` are consistent with the visible code structure and input descriptors.
- The screen is deterministic and stdlib-only by inspection, but I did not execute it.

Major closure failures / substitutions:

1. **Binding question substituted with descriptor/class-prior ranking.**  
   The question asks whether an FDA-approved molecule binds the Q141K NBD and could rescue trafficking. The code performs no docking, no conformer generation, no side-chain mutation modeling, no binding-energy estimate, no solvent/membrane/dimer context, no ER trafficking model, and no Q141K-vs-WT selectivity model.

2. **Positive-control validation is not independent.**  
   CFTR correctors are assigned the maximum class prior (`cftr_corrector: 1.00`) and decoys are assigned `0.15`. The maximum possible score for an otherwise-perfect decoy is `(0.15)^(1/5) = 0.684`, exactly the reported decoy max. Therefore “all CFTR controls above decoy max” is mostly a consequence of the hard-coded S4 prior, not evidence that the pocket heuristic detects chaperone-like binding.

3. **Dominant uncertainty is named but not tested.**  
   README says S4 class-prior weights are the dominant uncertainty, but no sensitivity analysis perturbs S4, pocket radius, charge model, or threshold. The ranking and GREEN verdict are therefore not robustly established.

4. **The “Q141K pocket” is a WT CA-neighborhood proxy.**  
   The pocket is all residues within 10 Å of Q141 CA in a WT AlphaFold monomer. No lysine side chain is placed, no rotamer/protonation is modeled, no induced conformational change is represented, no solvent exposure or true cavity volume is computed, and residue charge is counted crudely. This is not a physical pocket model.

5. **ATP/non-inhibition claim is unsupported.**  
   The output claims the site is distinct from the ATP pocket and therefore “would NOT compete with ATP” or inhibit transport. The code only checks CA distances to Walker A and ATP loop 2; it does not dock ligands or test allosteric inhibition. ABCG2 inhibitors score highly in the raw list, showing the heuristic can elevate molecules with the opposite functional profile.

6. **Localization / exposure not closed.**  
   ABCG2’s NBD is cytosolic in enterocytes/renal cells. The code uses `pk_grade = oral_bioavailable` but does not evaluate intracellular free concentration, tissue distribution, transporter access, ER exposure during folding, plasma protein binding, dose, Cmax, Kd/IC50, or whether compounds reach the site at concentrations compatible with rescue.

7. **Safety/off-target closure absent.**  
   The top 10 include strong pharmacological agents/classes: lumacaftor/ivacaftor, tafamidis, diflunisal, bile acids, deflazacort, minocycline, ambroxol, vorinostat. The implementation does not model toxicity, drug interactions, ABCG2 substrate/inhibitor risk, corticosteroid effects, HDAC-inhibitor pharmacology, NSAID risks, or chronic-use feasibility. Phase 0 framing must stay strict.

8. **Stored-but-unused inputs.**  
   `alphafold_Q9UNQ0_confidence_v6.json` is included and described as an input but is not loaded by `analyze.py`; pLDDT is instead read from PDB B-factors. This is not fatal, but the artifact should say the confidence JSON is provenance/backup, not an implemented input.

9. **Implementation/documentation mismatches.**
   - Top script docstring says shortlist threshold `>= 0.55`; actual code and outputs use `0.75`.
   - `write_summary()` says diversity filter “max 2 per class”; actual main code uses `max_per_class=1`.
   - `screening_results.json` methodology says “Library 135 << full DrugBank”; actual library/output size is 134.
   - Reproduction command says `cd experiments/...`; tracked path is `wiki/etc/experiments/...`.
   - Generated summary has at least one stale relative link shape (`../wiki/...`) from inside `outputs/`.

## New connections or implications

1. **The decoy maximum is a formula artifact.**  
   The reported decoy max 0.684 equals `(0.15)^(1/5)`, i.e., a perfect decoy under S1/S2/S3/S5 with the hard-coded decoy prior. This means the central “above decoy max” validation is not an independent discovery signal.

2. **The heuristic confounds chaperones with ABCG2 inhibitors.**  
   Several ABCG2 inhibitor/substrate classes rank high in raw outputs. This connects directly to `abcg2-modulators.md` and supplement-stack caution: a molecule that fits the descriptor/pocket heuristic could still reduce urate efflux by inhibiting ABCG2.

3. **The right wet-lab readout must be functional urate flux, not just surface staining.**  
   A compound that increases membrane ABCG2 but inhibits transport, or binds WT and Q141K equally, is not a useful rescue. The validation protocol should pair 5D3/surface localization with basolateral-to-apical urate flux and WT/Q141K selectivity.

4. **Compounding is downstream of biological validation.**  
   Because 503A tiers and API availability are unverified and the screen does not establish rescue, comp-032 should not yet expand the compounding-pharmacy track except as a “candidate class requiring validation” note.
