# Independent comp review — comp-021

## Bottom-line verdict
**Action required / quantitative verdict invalid as written.** The curation matrix is a useful starting artifact, and the simple spread calculation is mostly reproducible by inspection, but the summary contract is not clean: several headline interpretations contradict the code/matrix, the comp-029 “re-run sensitivity” was not actually rerun and appears directionally wrong, provenance tiers overclaim primary verification for several IC50 values, the assay-format taxonomy is not enforced by code, and multiple wiki surfaces are stale or stronger than the artifact supports.

## Implementation and constraint closure

**What the code actually does**

- `analyze.py` reads:
  - `outputs/matrix.json`
  - `inputs/assay-formats.json`
  - `inputs/compound-list.json`
- It groups `matrix["records"]` by `compound`.
- It computes:
  - full spread = `max(ic50) / min(ic50)` for all numeric `ic50` values per compound;
  - “gut-luminal subset” = records with `gut_luminal_relevance_score >= 2`;
  - gut spread, median, and collapse ratio;
  - RA prior commentary from RA records with score ≥2.
- It writes `outputs/summary.md`.

**Implementation-closure problems**

1. **Assay taxonomy is loaded but not used to validate anything.**
   - `fmt_by_code = {f["code"]: f for f in formats["formats"]}` is built and then unused.
   - The code trusts the per-record `gut_luminal_relevance_score` already stored in `matrix.json`.
   - It does not verify that each `assay_format` code exists in `assay-formats.json`.
   - This matters because `matrix.json` contains `ELISA-LP-Ficolin3`, which is **not defined** in `assay-formats.json`, yet it is assigned score 2 and enters gut-relevant spread calculations.

2. **`compound-list.json` is loaded but not used.**
   - It provides scope/provenance metadata only.
   - There is no closure check that all compounds in scope are represented in the matrix, or that matrix compounds are in the declared list.

3. **README/code mismatch on unit handling.**
   - Code comment says records with differing units are dropped/split, but implementation does not drop or split. It simply calculates across all numeric IC50s and sets `units = next(iter(units))`.
   - This happens not to visibly break current records because each compound appears single-unit, but the implementation contract is false and would silently fail if mixed units entered.

4. **Ranges and censored values are collapsed to single points without sensitivity.**
   - Englberger 5–10 µM becomes 7.5 µM.
   - Cimanga/Mu 137–182 µM becomes 160 µM.
   - 3,5-diCQA `<10 µM` becomes 10 µM.
   - This is acceptable as a curation convenience only if labeled as point-estimate summarization; it is not a quantitative uncertainty propagation.

5. **RA gut-relevant subset is correctly computed by code but incorrectly described in text.**
   - Code includes RA records with score ≥2:
     - CELL-C3b 34 µM
     - H-CP 180 µM
     - H-CP alternate 160 µM
   - Code **excludes** H-AP 160 µM because score = 1.
   - `outputs/summary.md` nevertheless says: “CELL-C3b 34 µM, H-CP 160–180 µM × 2 papers, **H-AP 160 µM**: 34–180 µM.”
   - That sentence is not the implemented subset.

6. **“CELL-C3b + H-CP + ELISA-CP” is not the RA subset.**
   - The summary headline says the RA subset is “CELL-C3b + H-CP + ELISA-CP.”
   - There is no RA ELISA-CP record in `matrix.json`.
   - The actual RA subset is CELL-C3b + two H-CP records.

7. **“Three formats score ≥2” is false relative to `assay-formats.json`.**
   - `outputs/summary.md` §9 says “three formats score ≥2”: CELL-C3b, H-CP, ELISA-CP.
   - But `assay-formats.json` assigns score 2 to at least:
     - H-CP
     - ELISA-CP
     - ELISA-LP-WieLISA
     - ELISA-CP-WieLISA
     - CELL-C3b
   - Matrix also uses undefined `ELISA-LP-Ficolin3` with score 2.
   - This is a taxonomy/summary contradiction.

8. **Bupleurum assay labels are internally inconsistent.**
   - BPs record uses `assay_format: "ELISA-CP"` but `what_measured` says “LP via mannan-coated” and notes “BPs ELISA-LP 1057 µg/mL.”
   - Provenance calls it “ELISA-CP (LP-mannan).”
   - This should be normalized before any pathway-specific interpretation.

9. **The comp-029 sensitivity section is not implemented.**
   - `analyze.py` does not load or run comp-029.
   - It prints a qualitative paragraph asserting how comp-029 would change.
   - That paragraph is therefore a narrative extrapolation, not an artifact-derived re-run.

10. **The comp-029 extrapolation appears quantitatively wrong.**
    - `outputs/summary.md` says narrowing RA IC50 from log-uniform `[5,180]` to `[34,180]` tightens RA inhibition “around 0.85–0.95” with median “~0.88–0.92.”
    - But raising the IC50 lower bound from 5 to 34 µM should generally **lower**, not increase, the median RA inhibition under the same RA concentration prior.
    - A rough log-center check: RA concentration prior `[50,1100]` has geometric center ~235 µM; IC50 prior `[34,180]` has geometric center ~78 µM; Hill fraction ≈ 235/(235+78) ≈ 0.75, not ~0.9.
    - Therefore the “combined ratio improves from 1.10× to ~1.12–1.15×” claim is unsupported and likely directionally wrong unless a real rerun proves otherwise.

11. **Sensitivity wording misstates comp-029.**
    - comp-021 summary says “DAF α remains the dominant uncertainty driver per comp-029 §6,” while quoting `RA IC50 r = -0.658` and `DAF α r = +0.480`.
    - The comp-029 page says RA IC50 was the largest listed Spearman driver; the `+0.480` value was for DAF effective concentration, not necessarily α.
    - comp-029 did identify DAF surface engagement as the key wet-lab unknown, but the comp-021 wording conflates sensitivity coefficients and experimental priority.

**Constraint closure**

- **Reaction substrates/products:** The artifact catalogs assay substrates/readouts qualitatively: sheep/rabbit RBCs, IgM/mannan/LPS coatings, C3c/C5b-9/C4d readouts, purified convertase assays, C3b deposition. The code does not reason over substrates, products, serum dilution, or pathway components; it only uses stored IC50 and score.
- **Physiologic concentration vs IC50:** comp-021 does not independently model gut-luminal RA concentration, RA metabolism, protein binding, complement-component concentration, or residence time. It relies on comp-029 for RA concentration priors and adds a subjective assay-format relevance score.
- **Finite mass balance / replenishment / exposure time:** Not modeled. IC50 values are treated as static comparable points. Serum dilution and assay time are metadata, not computational inputs.
- **Localization / transport / physical access:** The “gut-luminal relevance score” encodes assumptions about assay geometry, but no sensitivity analysis tests whether H-CP should be score 2, H-AP score 1, ELISA-LP score 2, or CELL-C3b score 3. This subjective score is a dominant design decision.
- **Coproducts / off-targets / safety:** Not evaluated, except heparin/RA mechanism notes. This is acceptable for an assay-format mapping artifact, but summary language should not imply physiological efficacy or safety.
- **Sensitivity coverage:** Sensitivity covers only full vs score≥2 spread. It does not test:
  - excluding websearch/abstract-tier RA records;
  - including H-AP in RA gut-relevant subset;
  - treating CELL-C3b as mechanistically distinct from complement-cascade inhibition;
  - range endpoints instead of midpoints;
  - alternative gut-relevance thresholds.

## New connections or implications

- **The dominant uncertainty may be assay-score design, not just IC50 spread.** Because code trusts stored `gut_luminal_relevance_score`, a one-point scoring change for H-AP, ELISA-LP, or CELL-C3b changes downstream priors. This should be treated as a model input with sensitivity, not as fixed metadata.
- **A corrected comp-029 rerun may weaken rather than strengthen the RA arm.** Excluding the 5–10 µM purified-convertase lower bound raises the lower bound of IC50, likely lowering median inhibition under the same RA concentration prior. The current summary’s “improves to 1.12–1.15×” is not safe.
- **The right wet-lab implication is dose-response, not a single 100 µM RA arm.** If the stratified operative range is 34–180 µM, the §1.25 optional co-treatment should use at least a small RA dose series or explicitly justify a single concentration.
- **Heparin/suramin are useful assay-format controls, but they do not independently validate RA.** They show that same-pathway assays can agree and different-step assays can diverge; they do not prove Sahu 1999’s RA numbers until the primary paper is verified.
