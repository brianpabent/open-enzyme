# Independent comp review — comp-022

## Bottom-line verdict
Action required — the v1 cassette-ranking artifact is internally inspectable and its **v1** headline numbers match committed outputs, but the **v2 strict-tier interpretation is materially wrong/stale**. In particular, `wiki-archive.md` claims the v2 N-of-5 = 5 strict tier “IS the v1 top cluster” and confirms PTS1-blocked direct secretion; the actual `v2_shortlist.csv` strict tier includes non-PTS1-blocked `direct_natag_pts1ok` and `PglaA` rows, while several v1 top-cluster PamyB direct/PTS1-blocked rows are only N-of-5 = 4.

The computation is useful as a **sequence/cassette candidate ranking inside the tested koji-secreted design space**, not as a topology, physiological activity, oxygen, peroxide, or clinical-efficacy verdict.

## Implementation and constraint closure
What I traced:

- v1 inputs:
  - `inputs/Q00511.fasta` → asserted 302 aa in `analyze.py`.
  - `inputs/a_oryzae_codon_usage.json` → codon back-translation, CAI, rare-codon list.
  - `inputs/parts_list.json` → promoters, signal peptides, codon variants, secretion scaffolds, propeptide and N-glyc modifiers.
- v1 code:
  - Enumerates exactly `6 × 12 × 10 × 10 × 3 × 2 = 43,200` candidates.
  - Scores four implemented axes: CAI, v1 mRNA 5′ proxy, chaperone load, promoter × SP prior.
  - Does **not** use rare-codon penalty as a concordance model despite computing/outputting it.
  - Collapses 2,421 N-of-4 ≥ 3 candidate rows to 501 unique `(promoter, sp, codon, scaffold_base)` rows.
- v1 outputs:
  - `report.json`: total 43,200; N-of-4 = 4 count 195; N-of-4 ≥ 3 count 2,421; unique shortlist 501.
  - `top25.md` and `unique_cassette_shortlist.csv` support the v1 top cluster: `PamyB`, `SPamyB_pro`/`SPamyB`/`SPglaA_pro`, `5p_softened`, direct secretion, N191Q, low chaperone load.
- v2 code:
  - `build_protein_shortlist.py` collapses the 501 v1 shortlist to 106 protein-distinct precursor/fusion sequences.
  - `run_viennarna_mfe.py` folds 52 `(codon, sp)` 5′ mRNA windows with a constant 61-nt generic UTR.
  - `run_esm2_pseudo_likelihood.py` computes a **single-pass unmasked ESM2 log-prob proxy**, rescaled to “pseudo-pLDDT”; it is not real ESMFold pLDDT and not full masked pseudo-likelihood.
  - `analyze_v2.py` joins v1 and v2 scores and outputs 71 N-of-5 ≥ 4 cassettes, 4 N-of-5 = 5 cassettes.
  - `rerank_v2.py` is a second, conflicting output writer for the same v2 filenames with different cutoff logic and summary fields; this weakens the reproducibility contract unless one path is deprecated.

Constraint closure:

- Reaction substrates/products are **not modeled** in comp-022. Uricase chemistry requires urate + O₂ + H₂O and produces allantoin-pathway products plus H₂O₂. The ranking does not include urate concentration, Km, oxygen availability, H₂O₂ generation/scavenging, residence time, replenishment, or epithelial exposure.
- Physiological operating regime is **outside this artifact**. This is now correctly delegated in the corpus to comp-044/045 and validation §1.33.
- Localization is only partially modeled:
  - PTS1 risk is represented as a small chaperone/routing penalty and by C-terminal tag variants.
  - Actual secretion vs intracellular/peroxisomal localization is not simulated.
- Transport/access are not modeled:
  - No ABCG2 delivery, luminal urate replenishment, diffusion, matrix access, gastric/intestinal transit, or solid-state pore-fluid availability.
- Safety handling/off-targets:
  - No peroxide safety, antioxidant loss, viability, epithelial injury, or coproduct modeling.
- Sensitivity ranges:
  - v1 sensitivity is mostly structural/ranking by enumerated cassettes, not biological uncertainty.
  - Dominant uncertainties such as promoter strength, SP efficiencies, KEX2 penalties, glucoamylase glyc-load, physiological substrate, oxygen, and real topology performance are either fixed priors or deferred.

Stored-but-unused / implementation observations:

- JSON documentation fields such as `evidence`, `expected_cai_in_oryzae`, `expected_gc`, `literature_use_count_proxy`, and many `_meta` fields are provenance/documentation only, not model inputs.
- `rare_codon_definition.rscu_threshold` and `freq_threshold` are not used dynamically; the code uses `rare_codons_list`.
- `rare_penalty` is computed/output but not included in concordance or composite scoring.
- `signal_peptides[].sequence` is not used in v1 scoring; v2 uses SP sequences for protein and mRNA construction.
- v2 ESM scoring includes signal peptides, generic propeptides, carrier heads, KEX2 sites, uricase, and tags as precursor/fusion sequences. That is a secretion-context proxy, not a mature-product fold-quality model.
- v2 uses a truncated 60-aa glucoamylase carrier head for ESM scoring, while the design-space/chaperone model discusses full glucoamylase fusions. This makes fusion-vs-direct v2 fold-quality comparisons approximate.
- `direct_his6_pts1ok` is semantically confusing: the scaffold ID says `pts1ok`, but `pts1_blocked` is `true`.

## New connections or implications
- The v2 outputs weaken a simple “PTS1-blocked is strictly confirmed” narrative. PTS1-blocked cassettes survive the v2 N-of-5 ≥ 4 gate, but native-tag direct secretion also appears in the N-of-5 = 5 strict tier. PTS1 blocking remains biologically motivated by localization risk, but v2 ranking alone does not make it a strict winner.
- The v2 ESM model is better interpreted as a **precursor/secretion-context naturalness proxy**, not product fold quality. This matters for fusion scaffolds and signal peptides because mature secreted uricase will not include the signal peptide, and KEX2-cleaved products will not retain the carrier.
- Because comp-022’s top candidates are sequence-level refinements with zero marginal synthesis cost, the strongest grounded use is to pre-specify gene-synthesis variants inside §1.33/§1.9B, not to reprioritize wet-lab topology.
- The comp-022 framework remains valuable for future target-specific cassette design, but comp-030 already shows target-specific codon winners can differ. “5′-softened” should not become a universal rule.
