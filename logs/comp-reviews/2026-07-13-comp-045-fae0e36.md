# Independent comp review — comp-045

## Bottom-line verdict
Action required — the artifact is a useful deterministic plate-map/design generator, but the evidence-state implementation overstates isolated KatG/VHb support after splitting those modules into separate arms, and several corpus pages still contain stronger “chassis solves peroxide” / topology-implied wording than comp-045 supports.

## Implementation and constraint closure

I traced `inputs/design_factors.json` into `analyze.py`, `outputs/results.json`, and `outputs/summary.md` by inspection.

**What the computation actually does:**  
comp-045 does not model uricase kinetics, oxygen demand, peroxide diffusion, epithelial exposure, residence time, transport capacity, enzyme expression, or efficacy. It enumerates topologies, peroxide strategies, oxygen-support states, oxygen contexts, urate concentrations, controls, and randomized plate maps. That fits the stated “decision design, not pseudo-quantitative ranking” framing, but it cannot itself resolve which topology works.

**Arithmetic/design closure by inspection:**

- Base conditions: 19.
  - Intracellular EcN: 2 peroxide arms after duplicate compartment-matched catalase exclusion × 2 oxygen states = 4.
  - LamB-secreted EcN: 3 peroxide arms × 2 oxygen states = 6.
  - InakN-displayed EcN: 3 peroxide arms × 2 oxygen states = 6.
  - Koji secretion: 3 peroxide arms × no VHb = 3.
  - Total = 19.
- Wells per plate: 19 × 3 urate concentrations = 57 factorial wells; controls = 21 nonzero-urate controls + 3 zero-urate controls = 24; total = 81 wells. This matches README/summary/results.
- Plates: 3 biological runs × 2 oxygen contexts = 6. Deterministic shuffling uses `random.Random(P["random_seed"] + plate_id)`.

**Implementation concerns:**

1. **KatG/VHb evidence is over-assigned after factorial separation.**  
   Provenance explicitly says KatG and VHb were combined in key PULSE/Zhao comparisons and their independent contributions were not fully isolated. However, `grade()` assigns:
   - EcN secreted/displayed + intracellular KatG/native catalase + `oxygen_support: none` → `peroxide_status: indirect_empirical_support`.
   - EcN secreted/displayed + `vhb` + `peroxide_strategy: none` → `oxygen_status: indirect_empirical_support`.
   - Intracellular + `vhb` without KatG → `oxygen_status: direct_empirical_support`.
   
   These labels are stronger than the artifact’s own provenance. If the precedent is the **joint KatG+VHb module**, then KatG-alone and VHb-alone arms should be graded as “separated-arm proposed test” / “unresolved” or otherwise explicitly labeled as inferred from a joint-module precedent, not empirically supported as isolated modules.

2. **`topologies[].urate_importer` is stored but not used.**  
   Substrate support is inferred solely from `uox_compartment == "cytoplasm"`, not from `urate_importer`. In the current input this happens to align because the only cytoplasmic topology has `urate_importer: true`, but the code silently couples “cytoplasmic” to “importer-supported.” That should either become an assertion or use the explicit `urate_importer` field.

3. **`evidence_states` is documentation-only.**  
   The allowed state list is not checked against emitted statuses. This is not fatal, but a deterministic contract would benefit from asserting that `grade()` only emits declared states.

4. **`query-strategy.json` and several descriptive fields are not implementation inputs.**  
   `purpose`, `peroxide_strategies[].description`, `urate_concentration_roles`, `query-strategy.json`, and `evidence_states` are documentation/provenance rather than executable factors. That is acceptable if intentional, but they should not be described as “hard-gate definitions” without noting which fields are informational.

**Constraint closure:**

- **Reaction:** UOX consumes urate + O₂ and produces oxidative urate products/allantoin + CO₂ + H₂O₂. The artifact includes urate, product, H₂O₂, dissolved oxygen, viability, and localization readouts, but does not specify timepoints, oxygen setpoints, UOX/cell dose, catalase dose, assay limits, or stoichiometric mass-balance acceptance criteria.
- **Physiological concentration:** 0.59 µM is included, with 50 µM sensitivity and 250 µM PULSE benchmark. The design recognizes the physiological-substrate issue but does not check assay sensitivity at 0.59 µM or relate concentration to Km/oxygen demand.
- **Mass balance/replenishment/residence:** Not modeled. The design is a static plate assay; it does not include luminal replenishment, diffusion, transit/residence time, mucus, epithelial transport, or reabsorption.
- **Localization/transport/access:** Topologies encode cytoplasm, extracellular bulk, outer surface, and koji extracellular secretion. Localization is a required readout. The model does not specify how localization will be measured or how compartment-matched catalase constructs will be built/validated.
- **Coproducts/local peaks/redox:** H₂O₂ is measured, and limitations mention extracellular epithelial exposure. However, the plate design alone does not include an epithelial barrier readout; that is deferred to §1.36.
- **Safety handling:** The artifact remains Phase 0 design. It does not establish safety or clinical efficacy.
- **Sensitivity ranges:** The concentration range covers human-baseline, sensitivity, and PULSE benchmark substrate levels. It does not cover oxygen partial pressures, UOX expression levels, catalase loading, residence time, pH, survival, mucus/diffusion, or assay detection limits—the dominant experimental uncertainties after comp-044.

## New connections or implications

- The factorial separation of KatG and VHb is scientifically valuable, but it creates an evidence-labeling trap: any empirical-support label must distinguish “joint-module precedent” from “isolated-module precedent.” Otherwise the plate design will appear more evidence-backed than it is.
- The same reaction-site scavenger principle connects oral whole-cell UOX and intra-articular UOX: neither is solved by “chassis” or “proximity” labels alone; both require measured catalase capacity relative to local H₂O₂ flux.
- Because comp-045 includes 0.59 µM urate, assay sensitivity and blank correction become load-bearing. The design should not proceed with generic urate/product readouts unless the method is validated at sub-micromolar urate with inactive-UOX and zero-urate controls.
